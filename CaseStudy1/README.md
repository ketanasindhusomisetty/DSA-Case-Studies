Hacker News Story Ranking using AVL Tree
Objective
This project demonstrates how AVL Trees are used for ranking Hacker News stories based on scores.

Concepts Used
AVL Tree
BST Property
Rotations
Delete and Reinsert Strategy
Time Complexity
Insert: O(log n)
Delete: O(log n)
Description
The project explains why direct score mutation is unsafe in AVL Trees and demonstrates the correct delete-and-reinsert approach for maintaining balanced rankings.
