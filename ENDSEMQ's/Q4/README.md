# Pune-Mumbai Expressway Dynamic Toll Routing

## Objective
This project demonstrates shortest path computation in a dynamic toll-routing system using Dijkstra’s Algorithm.

## Concepts Used
- Weighted Directed Graph
- Dijkstra Algorithm
- Dynamic Edge Updates
- Priority Queue
- Path Reconstruction

## Description
The project models toll plazas and dynamic toll-cost updates on the Pune-Mumbai Expressway. It analyzes shortest path routing and the effect of live toll updates.

## Shortest Path
KIR → KHA → KRD → DEH → PUN

Minimum Toll Cost:
55

## Time Complexity
Dijkstra Algorithm:
O((V + E) log V)

## Conclusion
Dynamic graph routing efficiently adapts to changing toll conditions while maintaining optimal path computation.
