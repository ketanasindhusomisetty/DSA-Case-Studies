# Steel Rod Cutting using Dynamic Programming

## Objective
This project demonstrates how Dynamic Programming is used to maximize profit in the steel rod-cutting problem.

## Concepts Used
- Dynamic Programming
- Bottom-Up Tabulation
- Memoization
- Optimization
- Unbounded Knapsack

## Description
The project computes the maximum obtainable revenue by optimally cutting a steel rod into smaller pieces using Dynamic Programming techniques.

## Maximum Revenue
dp[10] = 30

## Time Complexity
- Time Complexity: O(n²)
- Space Complexity: O(n)

## Conclusion
Dynamic Programming efficiently solves the rod-cutting optimization problem while minimizing repeated computations.
